# 📋 Sistema de Tarefas em Java

Aplicação desenvolvida em Java para gerenciamento de tarefas via terminal, com operações básicas de criação, listagem, remoção e atualização de status.

## Funcionalidades
- Cadastro de tarefas
- Listagem dinâmica
- Remoção por índice
- Marcação como concluída

## Tecnologias
- Java
